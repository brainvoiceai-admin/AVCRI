📥 Download Therapy Data

Download existing therapy data for any date in Excel format. You can then modify the date column and re-upload for testing.

📤 Upload Therapy Data

Upload Excel file to create TherapyAllocation and Booking records for testing. Existing draft bookings for the target date will be deleted.

{% csrf_token %}
Instructions:
  1. Download: Select a date and download the Excel file with existing therapy data.
  2. Modify: Open the Excel file. You can change the date column to a different date for testing.
  3. Upload: Select the target date and upload the modified Excel file. This will create new TherapyAllocation and Booking records (status='draft') for that date.
  4. Test: Go to the Scheduling page and click "Schedule" for the target date to test the allocation algorithm.

Note: This tool only creates draft records. It does not interfere with existing scheduled therapies.

📋 Required Excel Columns:
Column Name Required Description
patient_reg_no Required Patient registration number
therapy_code Required* Therapy code (or therapy_name)
therapy_name Required* Therapy name (or therapy_code)
timeslot_code Required Time slot code (e.g., SLOT1, SLOT2)
date Optional Date (YYYY-MM-DD). If not provided, uses target_date from form.
required_therapist_roles_json Optional JSON array of required therapist roles
ext_int Optional External/Internal indicator
notes Optional Additional notes

* Either therapy_code or therapy_name must be provided.
