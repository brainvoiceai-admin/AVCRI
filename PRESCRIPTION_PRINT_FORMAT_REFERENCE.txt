KEY FORMATTING RULES
===================================================================================

1. HEADER:
   - Must be exactly: "THE ARYA VAIDA CHIKITSALAYAM AND RESEARCH INSTITUTE"
   - Date in DD/MM/YYYY format
   - "PHYSICIAN / PHARMACY / RESEARCH" on same line as date

2. TIME LEGEND:
   - Clean 3-column layout
   - All 9 time codes displayed
   - Readable spacing

3. SECTION ORDER (STRICT):
   - SUITE – GROUND FLOOR (DS-1 to DS-6, NR-7 to NR-14, NR-28 to NR-33)
   - FIRST FLOOR (NR-15 to NR-27)
   - COTTAGES – NEW BLOCK (CT-1 to CT-23)
   - GENERAL WARD ROOMS (MG, FG, CB rooms)
   - OP PATIENTS (OP rooms)

4. PRESCRIPTION TABLE:
   - Columns: Time / Usage | Items | Oil Class | Ingredients
   - NO separate Dosage column
   - Dosage MUST be inside Items column
   - Group medicines with + symbol
   - Dosage at end in brackets: [10 ml]
   - Format: Medicine1 + Medicine2 + Medicine3 — [dosage]

5. THERAPY TABLE:
   - SEPARATE table AFTER prescriptions
   - Columns: Therapy Name | Items | Oil Class | Time Slot
   - Therapy name in first column (NOT in Items)
   - Therapy medicines in Items column
   - Time slot MANDATORY

6. PATIENT INFO:
   - Room, Name on first line
   - Gender, Age, Doctor on second line
   - Display ONCE per patient

7. ORDERING:
   - Room order strictly as defined
   - Inside each room, preserve row order
   - Do NOT alphabetically sort

8. CONSTRAINTS:
   - Print-only (no UI changes)
   - No data model changes
   - No business logic changes
   - Clean, professional, print-ready layout
